# Ideas

Repositorio dedicado exclusivamente a guardar ideas. No se utiliza para código, pruebas, componentes ni documentación general de otros proyectos.

Las ideas pueden surgir durante una conversación, pero solo se registran cuando Juan Carlos pide documentarlas expresamente.

## Estructura

Cada idea se guarda como un archivo Markdown independiente dentro de la carpeta `ideas/`.

```text
ideas/
└── nombre-corto-de-la-idea.md
```

El nombre del archivo debe ser breve, descriptivo y usar minúsculas con guiones.

## Contenido sugerido de cada idea

- Título
- Fecha
- Problema u oportunidad
- Idea propuesta
- Objetivo
- Funcionamiento esperado
- Decisiones tomadas
- Preguntas o próximos pasos

Solo se incluyen las secciones que aporten información. Una idea inicial puede ser breve y ampliarse después.

## Regla principal

No se guardan conversaciones automáticamente. Se crea o actualiza una idea únicamente cuando Juan Carlos lo pide explícitamente.
